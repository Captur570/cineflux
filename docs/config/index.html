Scannez le QR code

Sur votre télé ShippoTV, ouvrez Réglages › Abonnement › « Avec mon téléphone », puis scannez le QR code avec l'appareil photo de ce téléphone.

Configurer votre télé

Collez ou tapez les identifiants de votre abonnement. Ils sont chiffrés sur ce téléphone : seule votre télé pourra les lire.

Vous pouvez aussi coller votre lien M3U complet (…/get.php?username=…) : identifiant et mot de passe seront remplis tout seuls.
